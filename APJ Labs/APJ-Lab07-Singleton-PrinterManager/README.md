# APJ Lab 7: Singleton Design Pattern

Application Programming in Java, INHA University in Tashkent, Fall 2026.

A shared university printer modelled with the Singleton pattern: a private constructor, a private static instance and a public static `getInstance()` ensure that only one `PrintManager` object exists. The driver obtains two references and shows that they point to the same object.

**Run:** compile the file in `src/` and run the class `U2510164_lab7`.
