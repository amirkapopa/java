# APJ Lab 10: Football Player Registration Form (JavaFX)

Application Programming in Java, INHA University in Tashkent, Fall 2026.

A JavaFX form for registering a football player: name, age and position (`TextField`), category (`RadioButton`s in a `ToggleGroup`) and skill level (`ChoiceBox`), arranged with `GridPane`, `VBox` and `HBox`.

- **Submit** prints the player's information to the console in a fixed format, and rejects an age that is not a number.
- **Clear** empties the fields and resets the selections.

**Run:** open the project in IntelliJ IDEA (Maven) and run `com.example.lab10u2510164.Lab10_U2510164`, or use `./mvnw javafx:run`.
