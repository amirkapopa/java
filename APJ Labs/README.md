# APJ Labs

Laboratory assignments for Application Programming in Java, INHA University in Tashkent, Fall 2026.

| Lab | Topic |
|---|---|
| [Lab 6](APJ-Lab06-Exception-Handling) | Exception handling: `throw`, `try`, `catch`, `finally` in an employee management system |
| [Lab 7](APJ-Lab07-Singleton-PrinterManager) | Singleton design pattern: a shared printer manager |
| [Lab 8](APJ-Lab08-Swing-Contact-Form) | Swing GUI contact form with `ActionListener` and `ItemListener` |
| [Lab 9](APJ-Lab09-Socket-Interest-Calculator) | Socket programming: a simple interest client and server |
| [Lab 10](APJ-Lab10-JavaFX-Player-Registration) | JavaFX football player registration form |

Each folder has its own README explaining the lab and how to run it.
