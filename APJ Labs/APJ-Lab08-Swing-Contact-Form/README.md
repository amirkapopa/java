# APJ Lab 8: Contact Form with Swing and AWT

Application Programming in Java, INHA University in Tashkent, Fall 2026.

A Swing contact form with a name and e-mail field, gender radio buttons in a `ButtonGroup`, a country `JComboBox`, a newsletter `JCheckBox` and a Submit button, laid out with `FlowLayout`.

Event handling: `ActionListener` for the button and the combo box, `ItemListener` for the radio buttons and the check box. Every interaction prints a message to the console, and Submit prints all form data.

**Run:** compile and run `src/ContactForm_U2510164.java`.
