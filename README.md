# Java projects

Java coursework and practice projects by Amir Pulatov (INHA University Tashkent, CSE).

| Folder | What it is |

| [Password Vault](Password%20Vault) | Midterm project: password vault with AES encryption, password generator and strength checker, console and Swing GUI |
| [Generics & Exceptions](Generics%20%26%20Exceptions) | Practice on generics (generic lists, key-value pairs, bounded types) and custom exceptions |
| [Mortage calculator](Mortage%20calculator) | Mortgage calculator refactored into OOP classes |
| [Java Tasks](Java%20Tasks) | Small exercises: factorial, power, Taylor series, even/odd, largest number |
